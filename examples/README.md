# Папка examples
Здесь лежат наглядные примеры работы агента. Это «витрина» проекта для преподавателя.
Внутри есть три подпапки:
- `input/` — примеры правильных запросов от инженера (Участник 3).
- `output/` — примеры успешных ответов и журналов (Участник 3).
- `errors/` — примеры запросов с ошибками (Участник 4).

*Важно:* Не используйте выдуманные инженерные данные. Берите только те примеры, которые подтверждены исходным ТЗ.
