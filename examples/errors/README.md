# Подпапка errors (Обработка ошибок)
Здесь хранятся примеры **некорректных** запросов, чтобы проверить, как агент справляется с плохими данными.

- **Участник 4:** Сюда нужно положить три файла:
  - `missing_parameter.json` (запрос без обязательного поля).
  - `invalid_unit.json` (запрос с неправильной единицей измерения, например, psi вместо bar).
  - `out_of_range.json` (запрос, где значение выходит за физические рамки, например, отрицательное давление).

*Цель:* Доказать, что агент не «падает» с ошибкой, а вежливо отказывает и объясняет, что именно не так с запросом.
