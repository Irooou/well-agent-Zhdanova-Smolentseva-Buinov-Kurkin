Здесь хранятся примеры **успешных** ответов агента и журналов его работы.

- **Участник 3:** Сюда нужно положить два файла:

  - `trace_example.json` (пример журнала действий, чтобы видеть, какие инструменты вызывались).

*Цель:* Показать, как выглядит финальный отчет агента и его «черный ящик» (логи).
