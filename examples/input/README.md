# Подпапка input (Входные запросы)
Здесь хранятся примеры **правильных** и корректных запросов от инженера к нашему агенту.

- **Участник 3:** Сюда нужно положить файл `successful_request.json`.
- **Что внутри:** Идентификатор запроса, тип задачи, ID модели, параметры эксперимента, значения и единицы измерения.

*Цель:* Показать, как должен выглядеть идеальный запрос, который агент без проблем поймет и обработает.
