# Папка mcp_server
Здесь будет храниться код MCP-сервера и адаптер к Petroleum Experts PVTP (через OpenServer).

**Ответственный:** Участник №2 (или тот, кто пишет серверную часть).
**Что здесь будет:**
- `server.py` — точка входа MCP-сервера.
- `adapter.py` — код, который переводит команды MCP в вызовы API OpenServer.
- `schemas.py` — Pydantic-схемы для аргументов инструментов.
