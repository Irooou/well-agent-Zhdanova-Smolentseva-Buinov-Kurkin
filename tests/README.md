# Папка tests
Здесь хранятся сценарии проверок и тестов. Это наш «отдел контроля качества».
Мы описываем, как система должна реагировать на плохие данные (например, нет параметра, неверные единицы или зависший сервер).

- **Участник 4:** `test_scenarios.md` (таблица со всеми сценариями ошибок и ожидаемым поведением агента).

*Важно:* Тесты — это доказательство того, что наш агент устойчив к сбоям.
