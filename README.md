# ИИ-агент для адаптации и проверки PVT-модели

## Краткое описание
Проект представляет собой ИИ-агента, который автоматизирует настройку композиционной PVT-модели скважины и проводит её независимую проверку по промысловым данным (ГКИ).

## Цель разработки
Сократить время ручного подбора параметров и минимизировать ошибки за счет использования LLM (для понимания запроса) и точного Python-кода (для расчетов и вызовов API PVTP).

## Решаемая инженерная задача
Подбор параметров BIC и Volume Shift для совпадения с лабораторными экспериментами (CCE, CVD, SEP) с последующей проверкой на реальных замерах газоконденсатного фактора (ГКФ).

## Основные функции агента
- Понимание запросов инженера на естественном языке.
- Проверка единиц измерения и диапазонов.
- Взаимодействие с ПО PVTP через MCP-сервер.
- Формирование плана изменений модели (с подтверждением).
- Генерация отчетов с цитатами и логами.

## Архитектура (кратко)
LLM -> Pydantic (валидация) -> MCP-Клиент -> MCP-Сервер -> Python-Адаптер -> PVTP (OpenServer).

## Используемые технологии
- Python 3.x
- LangGraph (оркестрация)
- Pydantic (валидация)
- FastMCP (протокол MCP)
- Petroleum Experts PVTP (OpenServer)
