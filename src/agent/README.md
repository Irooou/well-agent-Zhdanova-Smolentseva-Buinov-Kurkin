# Папка src/agent
Здесь будет храниться основной код логики агента (оркестрация, вызовы LLM, LangGraph).

**Что здесь будет:**
- `graph.py` — описание графа состояний (StateGraph).
- `nodes.py` — функции-узлы (вызов LLM, вызов MCP, проверка допусков).
- `state.py` — dataclass (или Pydantic-модель) для хранения состояния.
