# Папка schemas
Здесь хранятся строгие JSON-схемы (контракты) обмена данными. 
Это «правила игры»: как агент принимает запрос и в каком виде отдает ответ.

- **Участник 2:**
  - `mcp_tools.json` (описание инструментов, которые агент может вызывать).
  - `agent_request.json` (структура входящего запроса от инженера).
  - `agent_result.json` (структура итогового ответа агента).

*Важно:* Это самые важные файлы для программистов. Если вы меняете название поля в коде, сначала поменяйте его в этих схемах и согласуйте с Участником 2.
